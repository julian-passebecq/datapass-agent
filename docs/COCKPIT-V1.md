# Agent cockpit v1

Agent 0.9 adds `activate().cockpitV1` while retaining `store`, `openWorkspace`, `installed`, `activationMs`, and `getDevelopmentObservations`. The canonical repository remains `julian-passebecq/agent-vscode`. NIGHT4 interfaces are pinned from galaxy-prompt-spec `92d256f75e334b685fb327ab552e718fbb51f001`; the additive `getScopes()` discovers only host-reviewed scopes.

The facade exposes `capabilities`, `getSummary`, `getProviderConfiguration`, `reveal`, `subscribe`, `planExport`, `executeApprovedLocalExport`, and `getExportReceipt`. Every scoped call validates request ID, declared scope, source vector and policy revision. No grant exists until **Agent: Review Cockpit Scope** selects exact local sessions and stable organization, privacy-domain and project IDs. Title/path matches do not assign sessions across organizations. **Agent: Revoke Cockpit Scopes** removes grants. PM must use this facade, not the legacy mutable store.

Summary replies contain session/source IDs, recorded parent links, model/effort/mode, opaque repository/worktree identity, separate accepted-work and observed-plan groups, 24h/7d/30d sample metrics, and registered context/asset references. Replies are detached projections; page cursors are bounded. Missing and partial data remain explicit. Provider configuration comes from the existing Settings/Catalog collectors and sanitized config projection. Values carry source IDs; layers preserve origin and shadowing. CLI overrides and effective runtime remain unresolved. No credential payload, hook command, MCP URL/header, environment value or instruction content crosses the facade. Config reads execute no CLI or hooks. Discovered source IDs open only allowlisted local files, with linked paths rejected again at reveal.

`reveal` opens an independent scoped panel for project/session/settings/catalog, or an opaque discovered source in the editor. It accepts no arbitrary command or file path. Caller selections remain local. Events coalesce, use sequence/scope hashes, require summary resync after overflow, and isolate subscriber exceptions/rejections. Revoked scopes deny late reads.

**Agent: Open Compact** adds observation to the existing workspace and preserves all previous screens. Project filtering uses full canonical repository identity rather than a basename; worktrees retain separate session detail. Factory uses only recorded links and keeps separate roots. `UNKNOWN` remains visible. Metrics describe bounded recorded model-call samples, not productivity or subscription billing. Context and Asset gallery are separate full screens.

**Agent: Import Scoped Context and Asset Receipts** registers a locally selected, bounded `datapass.agent-scoped-inputs/1` JSON envelope with exact `scope` and `data: {contexts, acceptedWork, assets}`. Context fields are id, projectId, sourceIds, backend, generationId, queriedAt and state. Accepted summaries contain projectId, revision and open/active/done counts. Assets contain id, sourceId, sha256, bytes, producer (nullable) and an explicit FILE_OBSERVED/GENERATED_REPORTED/GENERATED_VERIFIED/SELECTED/PUBLISHED state. Import is inert; no remote URL/command is executed. Registered evidence does not establish consumption or independent generation verification. Brain/PM packages must produce and review this input; there is no ambient history lookup.

**Agent: Select Asset Root** selects bounded local raster images. Local observation produces FILE_OBSERVED with producer UNKNOWN and SHA256; a changed PNG does not prove generation. Preview opens the selected allowlisted file. Manifest assets remain references unless a local approved file exists.

**Agent: Inspect Selected Diagnostic Resources** first selects an existing reviewed scope and exact local files, then asks for UNKNOWN, Enabled or Disabled enabled-state metadata. Enabled/Disabled is a `HOST_REVIEWED_ASSERTION`, not an observed runtime state. Cancel creates no enrollment. The command does not enable, disable, execute or re-enable a script, task or service. Its native JSON result keeps observed metadata, one-hour staleness, absent/blocked sources and causality UNKNOWN separate. **Agent: Inspect One Reviewed Local Process ID** reads only the selected PID's metadata; it does not kill or control that process.

**Agent: Export Reviewed Incremental Sessions** requires an export-enabled reviewed scope, a local destination and approval of the specific plan counts/hash. Caller JSON cannot supply approval or a destination path. The selected native readers identify new, appended, rewritten and unchanged sources by native identities and content hashes. Composite cursors include organization/privacy/source/schema/redaction/policy generations. Partial final JSONL records are deferred. Changed sources produce explicitly labelled **selected full-session resnapshots** of curated user/assistant dialogue, using the existing JSONL reader and sanitizer; hidden reasoning, system/developer instructions, tool payloads, auth/environment snapshots and attachments are omitted. This is a shared curated pack, not a complete native archive. Existing native-history CLI and bundle callers remain unchanged.

Export stages and validates content-addressed objects, then atomically renames an immutable hashed manifest. That manifest is the cursor commit; recovery rebuilds cursor state only from valid commits. Cancellation/failure before commit advances no cursor. Repeat of a committed plan is idempotent. Concurrent exports do not steal the destination lock. Native histories/databases are never written; no automatic archive push is performed. Local cursor storage and actual export consent are separate from Marketplace/deployment approval.

Build/check/package use existing CI. `node scripts/smoke-night4.mjs` installs the actual VSIX into an isolated synthetic-home VS Code profile and verifies compact controls, local scope review, sanitized same-host facade replies, cross-org denial and scoped navigation. Its consumer driver proves the installed Agent contract; the PM lane owns final multi-product integration.
