# Agent MAF source integration — 23 October 2026

This successor to Agent source `cf2a9303d9eeaa784a0d8d05d5c6afe5a2df3bc1` connects PM's actual headless client to the existing Agent runner and a real Microsoft Agent Framework worker. The first backend is explicitly offline model replay with one exact reviewed file action. It adds native API 1.0.3 and private provider-kit 1.2.0. It is not a new Agent VSIX or release.

The runner retains exclusive durable intent, canonical repository leases, host review, scope/epoch revocation, cancellation and receipts. It verifies a host-registered worker/import inventory; no arbitrary task-supplied script, argv, environment, credential or model endpoint is accepted. A matching framework tool approval is persisted before the single permitted file action. Foreign/stale events and unknown outcomes cannot become completed receipts. A startup/cancellation race found with the real Python child was repaired.
