## Install and rollback

Download `agent-vscode-0.11.8.vsix` and `SHA256SUMS` from the private release and verify `Get-FileHash -Algorithm SHA256` against the published receipt. Install in a separate test VS Code profile using Extensions → Install from VSIX, or `code --user-data-dir <owned-profile> --extensions-dir <owned-extensions> --install-extension <vsix> --force`. Open **Agent: Open Workspace**. Keep provider/root configuration confined to authorized test fixtures. Review Workspace Trust normally.

To roll back, close the test window, reinstall the preserved 0.11.7 VSIX into those same isolated directories with `--force`, then reopen. Preserve the previous package and checksum; do not replace historical release assets. Reopening a scoped panel may require a fresh reviewed PM handoff. No Marketplace publication or production installation is part of this delivery.
