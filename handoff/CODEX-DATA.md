## node:sqlite in VS Code
`code --version` = 1.140.0 (x64), Electron 43.7.3 (string in Code.exe). Test run: `ELECTRON_RUN_AS_NODE=1 Code.exe -e "require('node:sqlite')"` gave Node 24.21.0, SQLite 3.53.4, `DatabaseSync` works (in-memory). Standalone `node -v` = v26.9.0. So `node:sqlite` is usable with no flag in this VS Code. Caveat: the check ran in the ELECTRON_RUN_AS_NODE process; the extension host runs the same Electron Node build, but it was not tested from inside an extension host. Also `node:sqlite` is still "release candidate" API (experimental warning on stderr), and for older VS Code (Node < 22.13) sql.js (WASM) would be needed. Use `new DatabaseSync(copyPath, {readOnly:true})` on a copy including -wal/-shm (live DBs are locked by Codex WAL; `state_5` and `thread_history_1` change every few seconds).
