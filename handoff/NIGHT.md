## Hard rules (unchanged)
- Local only. Never upload, never send activity anywhere. Never read or show auth files (`~/.claude/.credentials.json`, `~/.codex/auth.json`), tokens, env dumps. Redact with `src/util/redact.ts`.
- Never write to provider files (transcripts, rollouts, settings) except where a package below says "opt-in write", and then only after `ctx.confirm`, with a backup.
- Every value carries its evidence kind in a tooltip or legend (OBSERVED / DERIVED / INFERRED / UNKNOWN). No LLM judgement, no invented numbers, no pricing.
- Processes (git, gh, glab) only from a Feed, only when `ctx.trusted`, read-only commands, 5 s timeout, use `HARDEN` from `src/git/git.ts` for git. Network (gh / glab API) only when the screen's opt-in setting is on (default off), shows "off" state otherwise.

## How to add a screen (the seam is already in main)
- Your screen file already exists: `src/render/extra/<id>.ts` with `ready: false`. Fill it, set `ready: true`. **Do not edit `src/render/extra/index.ts`, `kit.ts`, `feeds.ts`, `src/render/workspace.ts`, `src/render/html.ts`, `src/ui/workspace.ts`, `src/model.ts`** (owned by the PM; ask in your report if you need a change).
- Helpers: `kit.ts` (`seg` toggles → `st.opts`, `opt`, `toolbar`, `actBtn` + `actions`, `ActCtx`), `feeds.ts` (`Feed`, `feedValue`), `workspace.ts` exports (`card`, `kpi`, `repoOf`, `titleOf`, `ago`, `stageStrip`, `usageLine`, `ctxBar`, `prettyModel`, `bytes`, `scopeKey`), `insights.ts` (`identityColor`, `isLive`, `outcome`, `compact`, …), `esc` from `html.ts`.
- `d.timeline?.(key?, limit)` gives event history. `s.facts` (model.ts `SessionFacts`) holds rich per-session data once the **data** package lands; until then handle `undefined` gracefully.
- Options: use `seg(st, '<id>.<name>', …)` with lowercase values; offer granularity (minute / hour / day / week), orientation (horizontal / vertical), chart type, group-by, depth where it adds readability.
- CSS: put it in the view's `css` string, every selector prefixed by a class unique to your screen (e.g. `.wk-…`). Use theme variables only (`--ok --warn --bad --accent --quiet --claude --codex --line --raise`, `--vscode-*`). Must read well in dark and light.
- Rows that represent a session carry `data-select="<key>"` so filter, j/k and the inspector work.
- New logic goes in its own file (`src/activity/<id>.ts`, `src/git/<id>.ts`, `src/feeds/<id>.ts`), tests in `test/<id>.test.ts` (node:test, fixtures under `test/fixtures/` only, no secrets).
- New settings: do not edit package.json; read them with `ctx.config('agent.<id>.<name>', default)` and list them in your report (PM adds the contributions).

## Done condition (every package)

Do not merge. Return ≤ 3 lines: branch, PR URL, what works / what is missing.
